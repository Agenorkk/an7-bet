# AN7 Bet — simulador esportivo privado

Aplicação pessoal de simulação de apostas esportivas, sem dinheiro real.

## Como usar
1. Abra `index.html` no navegador ou publique o repositório privado em um serviço de hospedagem estática.
2. Escolha cotações demonstrativas e monte um bilhete simples ou múltiplo.
3. Informe o valor fictício e registre a aposta.
4. No histórico, clique em **Simular resultado** para simular uma vitória ou derrota.

## Importante
- Saldo inicial fictício: R$ 1.000,00.
- Jogos, horários e cotações são exemplos demonstrativos; não são dados ao vivo nem previsões.
- Não há depósitos, saques, pagamentos ou dinheiro real.
- O histórico é salvo no armazenamento local do navegador e não sincroniza entre dispositivos.
- O botão de reinício apaga o saldo e o histórico guardados localmente.

## Arquivos
- `index.html`: aplicação completa (HTML, CSS e JavaScript), sem dependências externas.
